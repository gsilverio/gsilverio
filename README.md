## 01 ─ SOBRE MIM

Sou desenvolvedor de software com atuação na construção, evolução e sustentação
de **aplicações corporativas, APIs e integrações entre sistemas**.

Minha principal experiência está no ecossistema **.NET**, trabalhando com
arquitetura, modelagem de domínio, regras de negócio, persistência,
processamento assíncrono e integrações externas. Também atuo no frontend com
**React e TypeScript**, desenvolvendo interfaces para operações complexas,
fluxos administrativos e grandes volumes de dados.

Ao longo da minha trajetória, participei de projetos profissionais e
institucionais envolvendo documentos fiscais eletrônicos, monitoramento de
avaliações realizadas por Inteligência Artificial, observabilidade, feature
flags, autenticação centralizada e infraestrutura blockchain.

Trabalho com uma visão ampla do produto, acompanhando o fluxo desde a
estruturação do domínio e do banco de dados até a experiência entregue ao
usuário. Tenho contato frequente com refatoração de funcionalidades existentes,
investigação de falhas em produção e implementação de mudanças sem comprometer
processos já consolidados.

Busco construir soluções legíveis, confiáveis e preparadas para continuar
evoluindo conforme o negócio muda.

## 02 ─ PROJETO EM DESTAQUE

### `RESIDÊNCIA EM TIC — MCTI · SOFTEX · BRISA · UFG`

Participei do **Programa de Residência em TIC do MCTI-SOFTEX**, executado pela
**BRISA** em parceria com o **Instituto de Informática da Universidade Federal
de Goiás — INF/UFG**.

Durante o programa, participei do desenvolvimento da **Sala de Situação C4TIC**,
uma aplicação web criada para centralizar o monitoramento, a gestão e a
governança de avaliações realizadas por Inteligência Artificial.

```text
[ BACKEND        ]  C# · ASP.NET Core · Entity Framework Core
[ FRONTEND       ]  Next.js · React · TypeScript · Tailwind CSS
[ AUTHENTICATION ]  Authentik · OAuth2 · OpenID Connect
[ FEATURE FLAGS  ]  Unleash
[ AI GOVERNANCE  ]  Langfuse · Gestão e versionamento de prompts
[ OBSERVABILITY  ]  Prometheus · Uptime Kuma
[ BLOCKCHAIN     ]  Hyperledger Fabric · Chaincode API
[ DELIVERY       ]  Docker · GitLab CI/CD · Portainer
```

O produto reuniu diferentes módulos operacionais em uma única plataforma:

- dashboard com indicadores consolidados;
- monitoramento do ciclo de vida de jobs;
- timeline estruturada de eventos;
- gestão de avaliações por feature flags;
- automação baseada em indicadores de qualidade;
- gestão e versionamento de prompts;
- acompanhamento de SLA e disponibilidade;
- relatórios operacionais em XLSX;
- controle de usuários e permissões;
- monitoramento de infraestrutura blockchain.

O desenvolvimento ocorreu de forma incremental, utilizando issues, branches,
revisões de código e entregas contínuas. A solução também foi integrada a
serviços externos e disponibilizada na infraestrutura do ambiente atendido
pelo projeto.
